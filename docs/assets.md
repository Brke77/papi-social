# Görsel ve font kaynakları

`public/art/scene-0.svg`–`scene-5.svg` ve `avatar-0.svg`–`avatar-5.svg`, projedeki `scripts/generate-art.mjs` ile üretilen özgün geometrik vektör çizimlerdir. Gerçek kişi, gerçek marka logosu veya internetten alınmış görsel yoktur. Profil adları ve gönderiler kurgusal örnek verilerdir.

Geist Variable, `@fontsource-variable/geist` npm paketinden yerel sunulur. İkonlar Lucide React paketinden gelir. Bağımlılık lisanslarını yayın öncesi yazılım envanterinde inceleyin.
